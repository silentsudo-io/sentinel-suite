# 🔭 The Observatory

**Rung 3 · the human interface to your recorded outcomes.** The counterpart to the ML Lab: the Lab
fits, the Observatory lets you look.

## What's here
- **`SentinelLens_v1_1_0.cs`** — the lens over the excursion corpus.

⚠ **Partial release.** The Observatory is consolidating the Lens, the Dashboard's excursion tab and
`SentinelExcursions` into a single surface, and that work is still in progress. What ships here is the
Lens; the rest follows as it stabilises.

## Install
1. Copy [`../runtime/`](../runtime/) (shared runtime — once) and this folder's `AddOns/` into
   `Documents\NinjaTrader 8\bin\Custom\`.
2. Press **F5** in the NinjaScript Editor.
3. Right-click a chart → **Indicators** → **Sentinel**.
